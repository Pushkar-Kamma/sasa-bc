# SASA BC website mockup

Responsive static website mockup for Bellevue College's South Asian Student Association.

The home, About, leadership, and event pages are `index.html`, `about.html`, `team.html`, and `events.html`. Team portraits and event photography are placeholders until SASA provides images. The Events page has a curved, scroll-following kite path.

Typography pairs Playfair Display (bold/black) display lettering and DM Sans body text with Raleway section headings and Poppins buttons. On the homepage, the impact section uses light cream and the SASA introduction uses a deeper warm cream.

## Deploy

Pushing to the `main` branch automatically publishes the site to GitHub Pages using the workflow in `.github/workflows/pages.yml`.

Live site: https://pushkar-kamma.github.io/sasa-bc/
